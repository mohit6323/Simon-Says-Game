# Simon Says Game

A browser-based memory game built using **HTML, CSS, and JavaScript**. The game generates a sequence of colors that the player must remember and reproduce correctly. The sequence becomes longer with each level.

## Features

* Randomly generated color sequences
* Progressive level system
* Interactive button animations
* User input validation
* Game-over detection
* Restart functionality
* Simple and responsive interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Play

1. Open the game in your browser.
2. Press any key to start the game.
3. Observe the button that flashes.
4. Click the buttons in the same order as the generated sequence.
5. Successfully completing a level adds another button to the sequence.
6. Clicking the wrong button ends the game.
7. Restart the game and try to achieve a higher level.
